# GSQZT full-stack

## Запуск
Нужен Node.js 18+.
1. Распакуй архив.
2. Открой терминал в папке `GSQZT/server`.
3. Создай файл `.env` на основе `.env.example` и задай длинный случайный `JWT_SECRET` (32+ символа).
4. Запусти `npm start` (устанавливать npm-пакеты не нужно).
5. Открой http://localhost:3000 — не открывай index.html напрямую.

## Уже работает
Регистрация, вход, хеширование паролей через Node crypto scrypt, токены с подписью HMAC, профиль, каталог релизов, оценки, публикация/чтение рецензий. Данные сохраняются в `server/data.json`.

## Для публикации
Это локально запускаемый backend, не размещённый в интернете. Перед production настрой HTTPS, уникальный секрет через переменные окружения, ограничение CORS, резервное копирование данных, защиту от перебора паролей и модерацию. JSON-хранилище подходит для прототипа и одного процесса; для большого сайта замени его на PostgreSQL.
